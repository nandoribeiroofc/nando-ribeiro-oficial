# Nando Ribeiro — O Top do Bailão

Site estático oficial, pronto para GitHub + Cloudflare Pages.

## Atualizações simples
- Agenda e vídeo: edite `assets/site.js`.
- Fotos: substitua arquivos em `assets/images/` mantendo os nomes ou ajuste o `index.html`.
- Contato/Instagram: procure os links no `index.html`.

## Cloudflare Pages
Este projeto possui `index.html` na raiz e não precisa de framework. Conecte o repositório no Cloudflare Pages.
